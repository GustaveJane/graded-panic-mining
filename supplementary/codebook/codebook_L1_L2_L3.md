# L2 编码框架：正式定义与边界规则

**范围**：A1–A4、B1–B4、C1、D1（共 10 类，即实际交付数据中出现的全部 L2 码位）
**权威取值来源**：`doc_taxonomy_mapping.csv` 的 `nature_detail` / `nature_detail_cn` 列（278,971 行）
**导出日期**：2026-10-09

---

## 一、层级结构与硬约束

| 层 | 字段 | 取值 | 约束 |
|---|---|---|---|
| L1 | `content_nature` | A / B / C / D / N | 必填，单选 |
| L2 | `nature_detail` | A1–A4 / B1–B4 / C1 / D1 | 随 L1 变化，单选；**必须属于父类允许子集** |
| L3 | `panic_type` | P1–P8 | **仅当 L1 = A 时必填**，否则留空 |

**代码层硬约束**（`topic_llm_encode.py` 的 `validate()` 实现）：

```
allowed = {A: [A1,A2,A3,A4], B: [B1,B2,B3,B4], C: [C1], D: [D1], N: [""]}
1) nature_detail ∉ allowed[content_nature]  → nature_detail 置空
2) content_nature ≠ A                       → panic_type 置空
3) topic_id = −1（HDBSCAN 噪声簇）          → 直接判 N，L2/L3 留空，不调用 LLM
```

**L1 定义（供 L2 定界使用）**

| L1 | 中文 | English | 定义 |
|---|---|---|---|
| A | 原创情绪表达 | Original emotional expression | 第一人称表达自身情绪、处境或诉求；主线是"我的感受/我的处境" |
| B | 新闻转发/通报 | News relay / official briefing | 转述或讨论官方、媒体、机构发布的疫情资讯；作者为信息传递者 |
| C | 互助/求助 | Mutual aid / help-seeking | 以获取具体外部资源为目的的求助（含求助方式、联系方式、扩散诉求） |
| D | 闲谈/生活吐槽 | Casual talk / daily life | 与疫情弱相关或无关联的日常内容 |
| N | 噪声/未归类 | Noise / unclassified | 广告、无意义内容、无实质纯转发；仅对应 `topic_id = −1` 与兜底失败项 |

## 三、逐类正式定义与边界规则

### A 类（原创情绪表达）

#### A1 情绪宣泄

**定义**　作者以第一人称直白表达恐惧、焦虑、崩溃、无力或烦躁等负面情绪，包括对自身身体感受的担忧与对个人处境的情绪化倾诉。

**纳入**
- 直接情绪词：害怕、吓死、崩溃、救命、哭、慌、怕怕
- 自身身体感受与新冠联想的担忧：畏寒、发烧、38.8、干咳、低烧、乏力、量体温
- 个人处境的情绪化倾诉：隔离/停课/返工引发的烦躁，居家无聊、发胖、被憋坏

**排除**
- 为本人或亲友求医求治、寻床位、求药 → **A2**
- 为物资、线索、扩散而求助 → **C1**
- 转述或讨论官方/媒体资讯 → **B**
- 无情绪标记的纯事实陈述 → 不入 A 类

**边界规则**
| 对照类 | 判据 |
|---|---|
| A4 | **语气优先于强度**。情绪以反讽、戏谑、夸张调侃形式出现（阴阳怪气、玩梗、反话）→ A4；直陈痛苦 → A1 |
| A3 | **落点优先于提及**。落点在祈愿、鼓劲、期盼好转 → A3；落点在宣泄当下痛苦 → A1 |
| A2 | 是否指向"具体的医疗处置请求"。有 → A2；只表达担忧 → A1 |
| B | 主线是"我的感受" → A1；主线是"这条信息" → B |

#### A2 医疗求助 ⚠️（数据现名"纪念/致敬"，语义不符，见 §五）

**定义**　围绕本人或亲友的**医疗处置困难**寻求帮助或信息，重点是求医、求治、求药、求床位、求转诊渠道。

**纳入**
- 求救式呼救：救命、救救妈妈、求求大家
- 收治与床位：无法收治、没有床位、社区不接、反复就医无果
- 用药与器材：买不到药、缺药、PICC、透析、器械
- 特殊人群就医：孕妇产检、终止妊娠、预产期、肿瘤放化疗、老年痴呆患者
- 就医决策求助：不确定能否就医、需不需要去医院、如何转诊

**排除**
- 仅表达对自身症状的担忧 → **A1**
- 物资（口罩、防护服、代购、物流）求助 → **C1**
- 转述医疗科普 → **B4**
- 扩散寻人、信息线索类求助 → **C1**

**边界规则**
| 对照类 | 判据 |
|---|---|
| C1 | 求助对象是**医疗资源与处置**（就医、收治、用药、转诊）→ A2；是**物资、线索、寻人、扩散** → C1 |
| A1 | 是否含对第三方的具体请求。有 → A2；无 → A1 |
| B4 | 是"求助"还是"科普"：有请求对象与诉求 → A2；无 → B4 |
| L3（P1/P7） | L2 是**内容形态**维度，L3 是**恐慌诉求**维度，二者独立。同一文本可为 L2=A1 且 L3=P7。**禁止用 L3 替代 L2**（旧版曾将 P1 医疗求助并入 A2，此后 P1 应保持独立或按 §五 一并裁决） |

#### A3 希望/鼓励

**定义**　对疫情结束、康复或生活回归正常的祈愿与鼓劲，情绪基调为正向期待。

**纳入**　"疫情快点过去""求求赶紧结束""加油武汉""会好起来的""春暖花开""战疫必胜""平安"类寄语

**排除**
- 反讽式"加油"、阴阳怪气 → **A4**
- 转发官方通报或援助新闻 → **B**
- 对个人处境的痛苦宣泄 → **A1**

**边界规则**　与 A1 的判据是**落点**：文本收束在"希望/祝愿/鼓劲" → A3；收束在"痛苦/害怕" → A1。与 A4 的判据是**语气**：真诚祈愿 → A3；戏谑反讽 → A4。

#### A4 讽刺/调侃

**定义**　以反讽、自嘲、戏谑、玩梗等方式表达对疫情相关人事的情绪与评价。

**纳入**　阴阳怪气、反话、"笑死""泪目但好笑"、玩梗、段子、自嘲（胖十斤、被逼成大厨）、带戏谑语气的质疑

**排除**
- 严肃的事实质疑与批评（无戏谑语气）→ 视主体归 **B3**（政策）或 **B1**（数据）
- 直陈情绪 → **A1**

**边界规则**　与 A1 的判据是**是否存在戏谑/反讽的语言标记**（引号反用、夸张、谐音梗、网络流行反语），而非情绪强度高低。该类为 A 类中规模最大者（34,692 篇），与 A1 最易混淆，建议对外文档中明确"语气标记优先"这一条。

### B 类（新闻转发/通报）

**L1 定界**　正文主体是信息本身 → B；主体是个人感受 → A。若"转发理由"含强烈个人情绪但正文为资讯，**以正文主体归 B**，L3 留空。

#### B1 国内疫情数据

**定义**　国内确诊病例、疑似、死亡、治愈等数据，以及疫情通报、病例轨迹、风险等级。
**排除**　防控措施 → B3；境外数据 → B2；科普解释 → B4。

#### B2 国际疫情动态

**定义**　境外国家/地区的疫情数据与防控动态，含境外疫情相关的政治与社会议题。
**排除**　中国境内数据 → B1；国际比较若落脚于中国政策 → B3。

#### B3 政策干预信息

**定义**　封城/封控、隔离、复工复学安排、交通管制、健康码、核酸检测政策等官方防控措施。
**排除**　疫情数据 → B1；医疗救治方案 → B4；个人对政策的情绪反应 → A 类（A1 或 A4）。
**边界规则**　政策**文本**本身 → B3；对政策的**情绪反应** → A 类。二者可同时出现在一条长文本中，以篇幅主体判定。

#### B4 医疗/科普信息

**定义**　病毒机理、传播途径、症状谱、防护措施、疫苗、口罩标准、辟谣等科普性内容。
**排除**　具体个案求助 → A2 或 C1；政策通告 → B3。
**边界规则**　与 A2 的判据是"是知识还是请求"：提供普适知识 → B4；指向具体个案的资源请求 → A2。

---

### C 类（互助/求助）

#### C1 互助/求助

**定义**　以获取具体外部资源为目的的求助与互助，通常包含求助方式、联系方式或扩散诉求。

**纳入**　口罩与防护物资求助、代购与物流、求助信息线索、寻人找人、病情扩散扩散帖
**排除**
- 医疗处置类求助（收治、用药、转诊）→ **A2**
- 纯信息转述 → **B**
- 无具体诉求的情绪表达 → **A1**

**边界规则**
| 对照类 | 判据 |
|---|---|
| A2 | 诉求资源是**物资/线索/扩散** → C1；是**医疗处置** → A2 |
| A1 | 是否存在明确的资源请求对象。有 → C1；无 → A1 |
| B | 是"求"还是"告知"。求 → C1；告知 → B |

---

### D 类（闲谈/生活吐槽）

#### D1 日常生活吐槽

**定义**　日常起居、居家生活、宠物、饮食、体重、追剧、天气、娱乐等生活化内容。

**纳入**　做饭与厨艺、体重增减、宠物、追剧、返乡与出行生活、季节与天气、社会娱乐话题
**排除**
- 含明确疫情情绪表达 → **A 类**
- 转述疫情资讯 → **B**
- 具体求助 → **C1**
- 与疫情完全无关的纯社会话题（外域政治、明星八卦）→ 视内容归 **D1**（若为闲谈）或 **N**（若无实质内容）

## 四、跨类判定优先级（统一裁决顺序）

```
① 是否 N？   广告 / 无意义 / 无实质纯转发 / topic_id = −1  → N，L2、L3 留空
② 定 L1       A 情绪主线 / B 信息主线 / C 资源请求 / D 日常闲谈
③ 定 L2       必须落在父类允许子集内，否则置空
④ 定 L3       仅 A 类填写；B/C/D 一律留空
```

四条可操作的裁决规则：

1. **主体优于附带**：以篇幅主体判定，不以转发的附加评论判定。
2. **落点优于提及**：文本收束处的语义决定类别（用于 A1/A3 区分）。
3. **语气优于强度**：是否存在反讽/戏谑标记决定 A1/A4，与情绪烈度无关。
4. **请求优于情绪**：存在具体资源请求 → A2/C1；仅为情绪表达 → A1。

## 六、附：与 L3 恐慌诉求（P1–P8）的正交关系

L2 与 L3 是两个独立维度，**不得互相替代**：

- L2 = 内容形态（这条帖在说什么类型的事）
- L3 = 恐慌诉求（这条帖的恐慌指向什么），仅 A 类填写

交付数据中 L3 的码位—名称对照（`panic_type_cn`）：

| 码位 | 名称 |
|---|---|
| P1 | 医疗资源求助 |
| P2 | 生活物资焦虑 |
| P3 | 复工/复学焦虑 |
| P4 | 隔离/封控影响 |
| P5 | 情绪宣泄 |
| P6 | 信息寻求 |
| P7 | 症状/确诊担忧 |
| P8 | 出行/交通焦虑 |

> 注意：L2 的 A1 与 L3 的 P5 名称同为"情绪宣泄"，但含义层级不同，阅读时勿混用。历史版本曾讨论删除 P1（认为与 A2 重复），**该条修订未落实到数据中**（P1 仍存在 1,999–2,807 条），需一并裁决是否保留。
